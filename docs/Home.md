# GeoTracker documentation

GeoTracker is a self-hosted, privacy-first location timeline: one small program, one data folder, no cloud. These pages cover installing it, using it and running it.

## Start here
- **[Getting started](Getting-Started)**: pick an install method and be running in ten minutes
- **[Install with Docker](Install-with-Docker)**: Docker, Docker Compose and automatic HTTPS
- **[Install the program](Install-the-Program)**: bare metal on Linux, Raspberry Pi, macOS and Windows
- **[HTTPS](HTTPS)**: Caddy, nginx, Traefik, Cloudflare Tunnel, Tailscale

## Using GeoTracker
- **[Connecting phones](Connecting-Phones)**: OwnTracks, Overland, Colota, GPSLogger, Traccar, Home Assistant
- **[User guide](User-Guide)**: timeline, importing Google Timeline, family, share links, photos, the installable app
- **[Automations](Automations)**: geofencing: tell family, call webhooks, Home Assistant, ntfy, Telegram, Discord, Slack

- **[Configuration](Configuration)**: environment variables, maps, offline maps, place names, email
- **[Administration](Administration)**: users, backups and restore, upgrading, moving servers, command line
- **[Single sign-on](Single-Sign-On)**: OpenID Connect (Authelia, Authentik, Keycloak, …)
- **[Troubleshooting](Troubleshooting)**: symptoms and fixes
- **[API](API)**: REST API and ingest endpoints for scripts and apps
